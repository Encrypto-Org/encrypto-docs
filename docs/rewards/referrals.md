# Referral Program

Encrypto grows through word of mouth. The referral program rewards both the referrer and the new user for joining.

## How It Works

1. **Get your referral code.** Every Encrypto user has a unique referral code, accessible from the app dashboard.
2. **Share it.** Send the code or referral link to a friend. Share via text, DM, social media — however you want.
3. **Friend signs up.** When the new user creates an account using your code, the referral is tracked.
4. **Both earn points.** Once the new user completes KYC, both parties receive points.

## Rewards

| Recipient | Points | When |
|-----------|--------|------|
| **Referrer** (you) | 5,000 | When referred user completes KYC |
| **New user** (friend) | 1,000 | On account creation with valid code |

## Referral Link

Your referral link format:

```
https://app.encrypto.fun?ref=YOUR_CODE
```

When someone visits this link and signs up, the referral code is automatically applied.

## Tracking

The app shows your referral stats:

- **Total referrals sent** — How many people used your code
- **Pending** — Signed up but haven't completed KYC yet
- **Completed** — KYC approved, points awarded
- **Total points earned from referrals**

## Rules

- No self-referrals. You can't refer your own accounts.
- One referral per person. Each new user can only use one referral code.
- Referral codes don't expire.
- Points are awarded after the referred user completes KYC (not just signup).
- Encrypto reserves the right to modify the referral program terms.

## Why Referral-First

We're building in invite-only mode intentionally. Early access creates scarcity, referrals create network effects, and points create incentive alignment. The users who bring the most people in will be the most rewarded when the points program matures.
