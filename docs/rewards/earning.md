# Earning Points

Points are earned automatically through normal platform usage. No special actions required — just use Encrypto and points accrue.

## Earning Mechanics

### Transaction-Based Earning

Every card transaction earns points equal to the transaction amount in cents. A $50 purchase earns 5,000 points. A $5 coffee earns 500 points.

This is intentionally generous. We want early users to accumulate meaningful point balances during the growth phase.

### Milestone Bonuses

One-time bonuses for completing key actions:

| Milestone | Points | Description |
|-----------|--------|-------------|
| Account created | 5,000 | Welcome bonus |
| KYC approved | 10,000 | Identity verification complete |
| First deposit | 2,500 | First USDC deposit received |
| First card spend | 2,500 | First card transaction |
| First P2P send | 1,000 | First peer-to-peer transfer |
| Connect X account | 500 | Link your Twitter/X profile |
| Refer first friend | 5,000 | First successful referral |

### Streak Bonuses

Consistent daily usage earns streak multipliers:

| Streak | Bonus |
|--------|-------|
| 7 days | 2x daily login bonus for the week |
| 30 days | 5,000 bonus points |
| 90 days | 25,000 bonus points + tier upgrade |

### Seasonal Campaigns

We run limited-time campaigns with boosted earning rates. These are announced via push notification and on the dashboard. Examples:

- **Double Points Weekend** — 2x on all card transactions
- **Referral Sprint** — 10,000 points per referral (limited time)
- **New Chain Launch** — Bonus for first deposit on a new network

## Points Multiplier

Your tier determines your earning multiplier:

```
Points Earned = Base Points × Tier Multiplier

Example (Gold tier, $100 purchase):
  Base: 10,000 points
  Multiplier: 2x
  Total: 20,000 points
```

## Points History

Every point transaction is logged with:
- Amount earned
- Reason (purchase, referral, milestone, etc.)
- Timestamp
- Running balance

View your full points history in the Rewards section of the app.
