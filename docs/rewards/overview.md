# Points & Rewards

<span class="badge badge--live">Live</span>

Encrypto rewards users for every meaningful action on the platform. Points are earned through usage, referrals, and engagement — and they'll be redeemable for real value.

## Why Points

Points serve two purposes:

1. **User retention.** Reward consistent usage and create a reason to stay engaged.
2. **Airdrop positioning.** Points accumulate toward future token eligibility. Early users who contribute the most activity will be recognized.

## Points Balance

Your points balance is displayed on your dashboard and accrues in real time. Every qualifying action credits points immediately.

## Current Earning Actions

| Action | Points | Frequency |
|--------|--------|-----------|
| **Account creation** | 5,000 | One-time |
| **Complete KYC** | 10,000 | One-time |
| **First card transaction** | 2,500 | One-time |
| **Card transaction** | 1x spend amount | Per transaction |
| **P2P send** | 500 | Per transaction |
| **Referral (referrer)** | 5,000 | Per referred user |
| **Referral (new user)** | 1,000 | One-time |
| **Daily login** | 100 | Daily |

Points values are subject to change as the program evolves.

## Tiers

As you accumulate points, you unlock higher tiers with better benefits:

| Tier | Points Required | Benefits |
|------|----------------|----------|
| **Base** | 0 | Standard access |
| **Silver** | 25,000 | 1.5x points multiplier |
| **Gold** | 100,000 | 2x points multiplier, priority support |
| **Platinum** | 500,000 | 3x points multiplier, early access to new features |
| **Diamond** | 1,000,000 | 5x points multiplier, exclusive events, advisory access |

## Redemption

Points will be redeemable for:

- **Fee credits** — Offset conversion fees and card fees
- **Higher credit limits** — Points tier influences credit line eligibility
- **Exclusive access** — Early access to new products (yield, credit, new chains)
- **Future token eligibility** — Details TBA

The exact redemption mechanics will be announced as we approach the token launch.
