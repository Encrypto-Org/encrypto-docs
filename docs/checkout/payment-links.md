# Payment Links

<span class="badge badge--live">Live</span>

Create shareable payment links that let anyone pay you in crypto or via PIX — no code, no integration, no Encrypto account required for the payer.

## How It Works

1. **Create a link** — Set the amount and description from your Encrypto dashboard or via the API
2. **Share it** — Send the link to anyone via text, email, social media, or embed it on a website
3. **Payer chooses method** — The payer selects from any supported cryptocurrency (on any chain) or PIX (Brazil)
4. **You get paid** — Funds arrive in your Encrypto wallet as USDC. Webhook notifications confirm payment.

The payer doesn't need an Encrypto account. They just need a crypto wallet or a PIX-enabled bank account.

## Use Cases

- **Freelancers** — Invoice clients with a payment link instead of sharing bank details
- **Small businesses** — Accept crypto payments without building an integration
- **Events** — Sell tickets or accept donations with a simple link
- **P2P commerce** — Sell anything to anyone, anywhere

## Features

| Feature | Details |
|---------|---------|
| **Amount** | Fixed or open (payer enters amount) |
| **Currency** | Any supported crypto or PIX |
| **Notifications** | Webhook on payment confirmation |
| **Expiration** | Optional — set a deadline for payment |
| **Description** | Custom description shown to the payer |

## API

Payment links can also be created programmatically via the [Checkout API](/checkout/api-reference). This enables automated invoice generation, recurring payment requests, and integration with existing billing systems.
